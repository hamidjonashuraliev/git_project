# Log

Loyiha ishlash jarayonida yuz bergan barcha voqealar
shu papkada avtomatik yozib boriladi.
Bu fayllarni qo'lda o'zgartirmang.

---

## Fayllar

### `data_loader.log`
`data_load.py` ishlaganda yoziladi.
Yahoo Finance dan aksiyalar yuklanishi,
saqlash jarayoni va xatoliklar qayd etiladi.

### `preprocesser.log`
`preprocessing.py` ishlaganda yoziladi.
Tozalash, encoding, scaling bosqichlari
va xatoliklar qayd etiladi.

### `feature_selection.log`
`feature_engineering.py` ishlaganda yoziladi.
Yangi ustunlar yaratilishi qayd etiladi.

### `train.log`
`train.py` ishlaganda yoziladi.
Modellar o'qitilishi, R2 va MAE
natijalari qayd etiladi.

### `evaluate.log`
`evaluate.py` ishlaganda yoziladi.
Model baholash natijalari qayd etiladi.

### `test.log`
`test.py` ishlaganda yoziladi.
Test natijalari qayd etiladi.
